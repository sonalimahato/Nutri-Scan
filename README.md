## 🌟 Overview
**Nutri-Scan Pro** is a cutting-edge open-source tool designed to tackle the global health crisis of obesity and poor dietary habits. By leveraging **Gemini 2.0 Flash**, the app converts simple meal photos into instant, accurate nutritional reports.

### 🚩 The Problem
Manual calorie counting is the #1 reason users abandon health goals. It is slow, tedious, and often inaccurate for home-cooked or "mixed" meals like stews and desserts.

### ✅ The Solution
A "No-Friction" interface where a single photo provides:
* **Ingredient Identification** (Even in complex mixed dishes)
* **Calorie & Macronutrient Estimation**
* **AI-Driven Health Verdicts**

## 🔧 Technical Innovation
This project follows an **Open Innovation** model:
1. **Bring Your Own Key (BYOK):** Users enter their own Gemini API Key in the secure sidebar. This ensures data privacy and zero hosting costs for the developer.
2. **Modular Design:** Built with Python/Streamlit, allowing for easy integration into hospitals, schools, or fitness apps.
3. **High Performance:** Uses the `gemini-2.0-flash-lite` model for near-instant responses.
